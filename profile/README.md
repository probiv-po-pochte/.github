# Пробив по почте: что можно узнать по email

**Пробив по почте** — это поиск публичных упоминаний адреса и проверка, не встречался ли он в известных утечках. Здесь собраны понятные инструкции для тех, кто хочет проверить собственный email или адрес с согласия его владельца.

## Начните с подходящего вопроса

- **Пробив почты и проверка утечек:** [пошаговое руководство](https://github.com/probiv-po-pochte/probiv-pochty).
- **Найти аккаунт по email:** проверяйте только открытые профили и исходные страницы; совпадение адреса ещё не доказывает, кому сейчас принадлежит аккаунт.
- **Проверить почту на утечки:** после обнаружения риска смените пароль, включите двухфакторную защиту и проверьте повторное использование пароля.
- **Поиск по почте:** учитывайте псевдонимы, старые адреса и ошибки в написании; не объединяйте разных людей по одному совпадению.

Почтовый адрес не даёт права получать доступ к чужому ящику, паролям или закрытым данным. Открытые упоминания могут быть устаревшими и требуют проверки первоисточника.
